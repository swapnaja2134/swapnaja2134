## ⭐ Featured project: Library Management System

A full-stack library app where students search, borrow and return books, and the admin manages books and members.

| | |
|---|---|
| 🌐 **Live demo** | [library-frontend-h1jx.onrender.com](https://library-frontend-h1jx.onrender.com) |
| ⚙️ **Backend code** | [Library-Management-Spring-Boot](https://github.com/swapnaja2134/Library-Management-Spring-Boot) |
| 🎨 **Frontend code** | [library-frontend](https://github.com/swapnaja2134/library-frontend) |

**What it does**
- 🔐 JWT login with **Admin, Librarian and Member** roles
- 📚 Search, borrow and return books, with overdue detection and late fines
- 🤖 **AI book search** with the Gemini API (falls back to normal search if the AI fails)
- 🛠️ Admin tools: add and remove books, member list, temporary password reset
- ✅ 19 JUnit and Mockito tests, secrets kept in environment variables
- 🚀 Deployed with Docker on Render, with a cloud MySQL database

<sub>It runs on free hosting, so the first load after a quiet period can take about a minute.</sub>
