## 🚀 Featured Projects

### 🤖 IntelliHire: AI-Powered Applicant Tracking System
> Upload a resume, get structured candidate data and a job-match score.

![Status](https://img.shields.io/badge/Status-In_Progress-f59e0b?style=flat-square)

`Java` `Spring Boot` `Spring Security` `JWT` `MySQL` `Apache PDFBox` `Groq API` `React.js`

```
Resume (PDF) ➜ PDFBox text extraction ➜ Groq LLM ➜ Structured profile + ATS match score ➜ Recruiter dashboard
```

- Parses PDF resumes with Apache PDFBox and extracts candidate details using the Groq API
- Scores each candidate against a job description (ATS match score)
- JWT authentication with role-based access for recruiters
- React dashboard for reviewing and comparing candidates

[![Backend Repo](https://img.shields.io/badge/Backend-View_Code-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/swapnaja2134/intellihire-backend)

### 📚 Library Management System
> Full-stack library app with role-based access and AI-powered book search.

![Status](https://img.shields.io/badge/Status-Live-22c55e?style=flat-square)

`Java` `Spring Boot` `Spring Security` `JWT` `Hibernate` `MySQL` `React.js` `Tailwind CSS` `Gemini API` `Docker`

- Role-based access for **Admin, Librarian and Member**, secured with JWT
- Book borrowing and returns with overdue detection and fine calculation
- Natural-language book search powered by the Gemini API
- **19 JUnit 5 / Mockito tests** covering the service layer
- Containerised with Docker and deployed on Render
